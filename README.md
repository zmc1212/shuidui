# 水碓 SHUI DUI — 机构复刻 No.06

《天工开物》水碓:立式水轮驱动水平碓轴,轴上 4 组拨杆相位差 90°,依次压下
碓杆尾、滑脱后碓头自由落体击臼——「役水而舂,其利百倍」。本站三维装配 +
凸轮-铰杆-落体运动学仿真,撞击频率与落体时间可验算,B 键查看复原总图。

## 机构与验算

```
尺寸(复原值,宋营造尺 0.3 m):
  立轮   R 1.3 m(12 辐 8 叶),轮心 y 1.55,下缘入水
  碓轴   Ø0.18 × 4.4 m;拨杆 4 组,回转半径 0.58,轴向间距 0.9,相位差 90°
  碓杆   长 3.0 m,铰点力臂比 尾 0.8 : 头 2.2;石杵 Ø0.26 × 0.5
  石臼   ×4,与拨杆一一对应

运动学(载入期断言):
  杆尾压下 0.225 m(拨杆接触区 ±22.5°,线性压下)
  碓头抬升 h = 0.225 × (2.2/0.8) = 0.62 m      ← 严格
  滑脱后自由落体 t = √(2h/g) = 0.356 s
  舂击频率 = 4ω/2π:ω=1.1 → 0.70 次/s;ω=1.8 → 1.15 次/s
  相位互锁:任意两碓撞击间隔 > 0.08 s(载入模拟断言)
```

**载入期自检**:30s 模拟的总撞击数与 4ω·t/2π 偏差 > 3 次、或任意两碓
几乎同时击(间隔 < 0.08s)即拒绝启动。

## 试验段(时间线 48s 循环)

| 键 | 阶段 | 内容 |

| 6 | 特写 | 1 号碓单周期:压下-滑脱-落体-击臼 |

仪表盘:轴速+频率、四碓高度相位曲线、单碓周期时间历史、撞击鼓点(四色)。
